保存の設定

ページ上の編集を GitHub のリポジトリへ保存するための鍵（トークン）を、このブラウザにだけ記録します。
  1. GitHub の Fine-grained token 作成ページを開く
  2. Token name は「レビュー索引」など。Repository access で「Only select repositories」→ anime-review-list を選ぶ
  3. Permissions の Contents を「Read and write」にして作成し、出てきた文字列を下に貼る
